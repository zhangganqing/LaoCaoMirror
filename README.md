# 全自动防老曹后视镜 v0.4.2

摄像头朝后当"后视镜"，YOLO 检测人脸 + SCRFD 五点对齐 + ArcFace 识别身份：

- **认出是老曹** → 1 秒内自动切屏到护身窗口；没设置时默认 Win+D 显示桌面
- **有人但认不出**（太远/模糊）→ 提示音 + 预览窗黄框预警，不切屏
- **每次防御自动留档** → 只保存该事件最高分脸照，之后在审核窗口批量判断和学习

## 文件结构

```
ui.py                开发入口: 自动选择可用 ONNX Runtime 后端
ui_cpu.py            CPU 版固定入口
ui_gpu.py            NVIDIA GPU 版固定入口
main.py              引擎 + 命令行入口(测试用)
config.json          配置(UI 里改, 也可手改)
laocao/              老曹照片、自动学习照片与本地审核队列
models/              3 个 ONNX 检测/对齐/识别模型
requirements-*.txt   CPU/GPU 互斥依赖
LaoCaoMirror*.spec   CPU/GPU 独立打包配置
test_switch.py       切屏/恢复回归测试(自建窗口, 不影响真实窗口)
test_resource.py     资源占用实测
软件需求设计书.md      设计文档
```

## 日常使用

**方式一：对应版本 exe 双击启动（推荐）**

```
dist\LaoCaoMirror-CPU\LaoCaoMirror-CPU.exe
dist\LaoCaoMirror-GPU\LaoCaoMirror-GPU.exe
```

- 普通电脑使用 CPU 版；NVIDIA 电脑且已配置 CUDA/cuDNN 时使用 GPU 版
- 整个对应版本文件夹必须一起拷贝，exe 不能单独拎出来
- `config.json` 和 `laocao/`(老曹照片) 就在 exe 旁边, 随时可改
- 首次启动要加载模型, 比脚本模式慢几秒, 属正常

**方式二：脚本启动**

```bash
python ui_cpu.py     # 固定 CPU 版
python ui_gpu.py     # 固定 NVIDIA GPU 版；缺依赖会明确报错
python ui.py         # 仅开发调试：自动选择可用后端
```

界面操作顺序（第一次）：

1. **设置** → 可选一个打开着的课件/文档作为护身窗口；不选择则检测时自动显示桌面
2. **框选检测区** → 在对话框画面上**按住左键拖框，可连续拖多个**（如门口一个方向、
   后门一个方向），拖错点「撤销上一框」→ 确定。框外的脸完全忽略（中间拍到你自己的
   部分零误报）；一个框都不拖 = 全画面检测。确认后立即生效，巡逻不中断
3. **启动巡逻**。预览窗实时显示身后画面，右上角状态灯：🟢巡逻 / 🟡警戒 / 🔴已防御
4. 发生防御后只需在老师离开时点「老曹已走 · 恢复界面」，照片会继续保留在审核队列
5. 有空时打开「审核记录 (N)」，勾选多张照片后批量标为老曹或误报；确认照片无需重启，下一帧起即可参与识别

之后日常只需启动与电脑匹配的入口 → 启动巡逻。

摄像头：设置里的"摄像头编号"默认 0，若朝后的外接摄像头是索引 1 就改成 1。

## 设置项(界面里可改, 存 config.json)

| 项 | 默认 | 说明 |
|---|---|---|
| 护身窗口 | 空 | 从当前打开的窗口列表里选；不选或窗口失效时 Win+D 显示桌面 |
| 检测帧率 fps | GPU/开发 10；CPU 8 | 老曹是慢慢摸上来的, 降到 5 更省电(3帧确认≈0.6s) |
| 摄像头分辨率 | GPU/开发 1920×1080；CPU 1280×720 | 采集清晰度, 以摄像头实际支持为准(日志有实测值) |
| 自动对焦 | 开 | 后景总是模糊时关闭，再调手动焦距把焦点锁到后方通道 |
| 手动焦距 | 160 | 常见范围 0~255；驱动不支持时日志提示并忽略 |
| 自动曝光 | 开 | 后景过曝时关闭并调低手动曝光 |
| 手动曝光 | -6 | 越小画面越暗，Windows 摄像头常见范围 -13~-1 |
| 逆光补偿 | 关 | 光线反差大时可尝试；是否有效取决于摄像头驱动 |
| 检测阴影增强 | 关 | CLAHE 只增强检测副本，不改变预览；无法恢复纯白过曝细节 |
| 检测清晰度 | GPU/开发 960；CPU 640 | 流畅 640（低配 CPU）/ 均衡 960 / 高清 1280（高性能 CPU 或 GPU），越高远处小脸越容易检出，CPU 也越高 |
| 提醒阈值 | 0.35 | 相似度超过=疑似老曹: 急促提示音+橙框(不切屏) |
| 切屏阈值 | 0.50 | 相似度超过=确认老曹: 立即切屏 |
| 确认帧数 | 2 | 连续命中 N 帧才切(防单帧误检) |
| 忽略小于画面占比 | 5% | 太远的脸不提醒 |
| 提示音 | 开 | 疑似老曹时响; 不戴耳机时建议关(出声会暴露) |

**相似度分档**: 普通陌生人路过=黄框静默; 疑似老曹=急促音+橙框; 确认老曹=切屏。
防御期间护身窗口自动保活；恢复和真假审核已经解耦。每次连续出现只保存一张最高分脸照到 `laocao/review_queue/`，记录跨重启保留。批量确认后才会热更新人脸库；自动学习照片最多保留 30 张，只清理最旧的 `learned_` 照片，手工照片永不自动删除。命令行按 R 只恢复、不处理审核记录。
即使没有点击恢复，只要连续 1 秒未识别到老曹，下一次再次识别就会建立新的审核记录；连续停留在画面中则只更新同一条记录的最高分照片，避免每帧重复保存。
课室多人场景: 每张脸只在首次入画时识别一次(帧间跟踪), 人数不影响占用。
窗口标题和事件日志会显示 CPU版/GPU版，并分别列出检测、关键点对齐、身份识别
三个模型的实际 provider。GPU 版不会静默退回 CPU；CUDA/cuDNN 不匹配时直接提示。

## CPU 性能与低配建议

多检测区现在会先合并成一个最小包围区域，只执行一次 YOLO，再过滤各框外的人脸；
检测区数量不再直接等于每帧推理次数。双 ROI、1280 检测尺寸的同机基准从约
**229 ms/帧降至 50 ms/帧（约 4.6 倍）**。

CPU 版的三个模型全部使用 ONNX Runtime CPU，不再携带 PyTorch、TorchVision 或
Ultralytics。`python test_resource.py` 会强制走 CPU 路径，避免开发机有独显时测错模式。
低核数电脑看到的“全机 CPU 百分比”会更高，这是同一工作量除以更少核心。
开发机当前高负载配置（1280 检测尺寸、24 fps、双 ROI）实测约占 3.15 个逻辑核，
折合 24 逻辑核整机 13%，内存峰值 306 MB；低配机器应按下方建议降低帧率和尺寸。

低配电脑建议先用：

- 摄像头分辨率 `1280×720`
- 检测清晰度 `流畅 640`
- 检测帧率 `5～8 fps`（若能稳定跟上再逐步加）
- 尽量框出真正需要监控的区域；多个框可以放心使用
- 只有后景偏暗时才打开“检测阴影增强”；它会增加少量图像处理开销

> ONNX Runtime 线程数限制为 2，避免小模型推理拉满所有核心。

## CPU / GPU 依赖与构建

第一次使用 GPU 版请先阅读 **[GPU 安装教程](GPU安装教程.md)**。教程解释了为什么
“能看到 NVIDIA 显卡/PyTorch 能用 CUDA”仍可能缺少 ONNX Runtime 所需的 DLL，
并分别提供打包版和源码版的完整安装、PATH 配置及验证命令。

两个版本必须使用不同虚拟环境，因为 `onnxruntime` 与 `onnxruntime-gpu` 不能混装：

```powershell
.\build_cpu.ps1     # 使用 .venv-cpu-build，目标 LaoCaoMirror-CPU
.\build_gpu.ps1     # 使用 .venv-gpu-build，目标 LaoCaoMirror-GPU
```

GPU 版用户需自行安装匹配的 NVIDIA 驱动、CUDA 12.x、cuDNN 9.x 和最新 MSVC
运行库，并保证相关 DLL 在 `PATH` 中。只有 PyTorch 自带 CUDA 运行库不够；GPU 版
检测到 CUDA provider 实际加载失败时会停止启动并提示，不会退回 CPU。脚本运行时也可分别安装：

```powershell
python -m pip install -r requirements-cpu.txt
python -m pip install -r requirements-gpu-source.txt   # 源码 GPU 版，自动安装 CUDA/cuDNN DLL
```

运行时不需要 `models/yolov8n-face.pt`；该文件仅保留用于重新导出或对照验证。

## 已知限制(v0.5 计划)

- 只认正面大脸：太远/侧脸/低头/口罩时识别不出 → 走提醒路径。多收集几张侧脸照片入库可改善
- 预览窗未做托盘静默：老曹盯你屏幕能看到界面(可手动最小化, 检测不受影响)
- 空人脸库时只提醒不切屏
- 摄像头对焦/曝光属性依赖硬件和驱动；不支持的廉价摄像头只能通过物理调焦、换角度或改善灯光解决

# 全自动防老曹后视镜 v0.2

摄像头朝后当"后视镜"，YOLO 检测人脸 + SCRFD 五点对齐 + ArcFace 识别身份：

- **认出是老曹** → 1 秒内自动切屏到护身窗口（课件/PDF 等正规界面）
- **有人但认不出**（太远/模糊）→ 提示音 + 预览窗黄框预警，不切屏
- **切屏后人工复核** → 确认是老曹则学习本次照片，误报则删除；两种选择都会恢复原界面

## 文件结构

```
ui.py                桌面界面(推荐入口): 预览/状态/事件/框选检测区/设置
main.py              引擎 + 命令行入口(测试用)
config.json          配置(UI 里改, 也可手改)
laocao/              老曹照片(手工照片 + 人工确认后自动学习的照片)
models/              检测+识别模型(已就位)
test_switch.py       切屏/恢复回归测试(自建窗口, 不影响真实窗口)
test_resource.py     资源占用实测
软件需求设计书.md      设计文档
```

## 日常使用

**方式一：exe 双击启动（推荐）**

```
dist\LaoCaoMirror\LaoCaoMirror.exe
```

- 整个 `LaoCaoMirror` 文件夹(约 1.4 GB)必须一起拷贝, exe 不能单独拎出来
- `config.json` 和 `laocao/`(老曹照片) 就在 exe 旁边, 随时可改
- 首次启动要加载模型, 比脚本模式慢几秒, 属正常

**方式二：脚本启动**

```bash
python ui.py         # 打开界面
```

界面操作顺序（第一次）：

1. **设置** → 护身窗口下拉里选你打开着的课件/文档窗口 → 保存（会自动重启引擎生效）
2. **框选检测区** → 在对话框画面上**按住左键拖框，可连续拖多个**（如门口一个方向、
   后门一个方向），拖错点「撤销上一框」→ 确定。框外的脸完全忽略（中间拍到你自己的
   部分零误报）；一个框都不拖 = 全画面检测。确认后立即生效，巡逻不中断
3. **启动巡逻**。预览窗实时显示身后画面，右上角状态灯：🟢巡逻 / 🟡警戒 / 🔴已防御
4. 发生防御后选择「确认是老曹 · 学习并恢复」或「误报 · 删除并恢复」。只有人工确认的照片才会加入图库，并且无需重启，下一帧起即可参与识别

之后日常只需 `python ui.py` → 启动巡逻。

摄像头：设置里的"摄像头编号"默认 0，若朝后的外接摄像头是索引 1 就改成 1。

## 设置项(界面里可改, 存 config.json)

| 项 | 默认 | 说明 |
|---|---|---|
| 护身窗口 | 空 | 从当前打开的窗口列表里选；不选则只提醒不切屏 |
| 检测帧率 fps | 10 | 老曹是慢慢摸上来的, 降到 5 更省电(3帧确认≈0.6s) |
| 摄像头分辨率 | 1920×1080 | 采集清晰度, 以摄像头实际支持为准(日志有实测值) |
| 检测清晰度 | 均衡 960 | 流畅 640（低配 CPU）/ 均衡 960 / 高清 1280（高性能 CPU 或 GPU），越高远处小脸越容易检出，CPU 也越高 |
| 提醒阈值 | 0.35 | 相似度超过=疑似老曹: 急促提示音+橙框(不切屏) |
| 切屏阈值 | 0.50 | 相似度超过=确认老曹: 立即切屏 |
| 确认帧数 | 2 | 连续命中 N 帧才切(防单帧误检) |
| 忽略小于画面占比 | 5% | 太远的脸不提醒 |
| 提示音 | 开 | 疑似老曹时响; 不戴耳机时建议关(出声会暴露) |

**相似度分档**: 普通陌生人路过=黄框静默; 疑似老曹=急促音+橙框; 确认老曹=切屏。
防御期间护身窗口自动保活；恢复是**手动复核**的——确认正确会保存本次最高分脸照并热更新人脸库，误报会删除待审照片。自动学习照片最多保留 30 张，只清理最旧的 `learned_` 照片，手工放入的照片永不自动删除。命令行按 R 仍是兼容的“仅恢复、不学习”。
课室多人场景: 每张脸只在首次入画时识别一次(帧间跟踪), 人数不影响占用。
有 NVIDIA 显卡的机器自动用 GPU 推理(日志显示"[算力] 推理设备: GPU")。

## CPU 性能与低配建议

多检测区现在会先合并成一个最小包围区域，只执行一次 YOLO，再过滤各框外的人脸；
检测区数量不再直接等于每帧推理次数。双 ROI、1280 检测尺寸的同机基准从约
**229 ms/帧降至 50 ms/帧（约 4.6 倍）**。

`python test_resource.py` 会强制走 CPU 路径，避免开发机有独显时测错模式。当前配置
（双 ROI、1280、10 fps）在 24 逻辑核笔记本上稳定段约占 1.0～1.6 个逻辑核，内存
约 0.77 GB。低核数电脑看到的“全机 CPU 百分比”会更高，这是同一工作量除以更少核心。

低配电脑建议先用：

- 摄像头分辨率 `1280×720`
- 检测清晰度 `流畅 640`
- 检测帧率 `5～8 fps`（若能稳定跟上再逐步加）
- 尽量框出真正需要监控的区域；多个框可以放心使用

> 虚高元凶是 torch/OMP 线程池自旋空转, 已通过 `OMP_WAIT_POLICY=PASSIVE` 修复。

## 命令行(测试用)

```bash
python main.py --source test_face.jpg --max-seconds 10        # 陌生人图片→提醒路径
python main.py --source laocao/某照片.jpg --max-seconds 12    # 老曹照片→切屏路径
python main.py --select-roi                                   # 命令行版框选
python test_switch.py                                         # 切屏/恢复闭环自测
python test_resource.py                                       # 资源占用实测
```

## 已知限制(v0.3 计划)

- 只认正面大脸：太远/侧脸/低头/口罩时识别不出 → 走提醒路径。多收集几张侧脸照片入库可改善
- 预览窗未做托盘静默：老曹盯你屏幕能看到界面(可手动最小化, 检测不受影响)
- 空人脸库时只提醒不切屏

# GPU 安装帮助设计

## 问题与目标

GPU 版当前能拒绝静默回退到 CPU，但错误只说缺少 CUDA provider，没有解释为什么“装过显卡驱动或 PyTorch CUDA”仍不算安装完成，也没有给普通用户可执行的安装顺序。目标是让用户在启动失败的当下就知道缺什么、教程在哪、如何验证，不需要自行搜索错误 DLL。

## 交互设计

GPU 模型加载失败时，引擎发出专用信号，由 Qt 主线程显示“GPU 环境未安装完整”对话框。对话框列出 NVIDIA 驱动、CUDA 12.x、cuDNN 9.x、VC++ 运行库和 `onnxruntime-gpu` 五项要求，展示当前错误，并提供“打开安装教程”按钮。GPU 版主界面也常驻一个“GPU 安装帮助”按钮，尚未启动时同样可打开教程。教程路径使用 exe/脚本当前目录，打开失败时将完整路径写入事件日志。

## 教程与分发

仓库根目录新增 `GPU安装教程.md`，覆盖显卡检查、源码运行和打包版两条路线、官方链接、PATH 配置、重启、验证命令及常见 DLL 错误。ONNX Runtime 1.26 对应 CUDA 12.x/12.8 与 cuDNN 9.x；Windows 需要 VC++ 2019 或更新运行库。GPU PyInstaller spec 将教程放到 exe 同目录，README 的 GPU 段落链接到教程。

## 验证

测试保证 GPU 缺失错误含五项依赖、教程路径和诊断命令；GPU 界面存在帮助按钮；spec 包含教程。保留现有 provider 防回退测试并运行全部自动测试、语法检查和 Qt 离屏弹窗/按钮专项检查。

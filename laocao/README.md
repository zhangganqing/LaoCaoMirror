把老师（要防的人）的照片放进这个文件夹，尽量覆盖不同角度（正面、侧脸、低头），
jpg/png 均可，文件名任意。手工增删照片后重启软件生效。

软件防御后会保存一张待确认照片。点击「确认是老曹 · 学习并恢复」后，照片会以
`learned_` 开头的文件名加入本目录并立即生效，无需重启；点击「误报 · 删除并恢复」
则不会入库。自动学习照片最多保留 30 张，只淘汰最旧的自动照片，不会删除手工照片。

仓库自带的 7 张参考照片来自公开网络，用于开箱即用的演示和识别。运行时生成的
`face_cache.json`、`.pending/` 和 `learned_*` 照片仍由 `.gitignore` 排除。
